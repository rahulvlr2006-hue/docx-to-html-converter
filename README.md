# DOCX TO HTML Converter

## Overview

DOCX TO HTML Converter is a desktop application developed using Python and CustomTkinter. It converts Microsoft Word (.docx) documents into clean HTML code while preserving document structure and formatting.

## Features

* Convert DOCX files to HTML
* Support for Heading 1, Heading 2 and Heading 3
* Paragraph conversion
* Bold text conversion
* Italic text conversion
* Underlined text conversion
* Bullet list conversion
* Table conversion
* Dark and Light theme support
* Browse and select DOCX files
* Save generated HTML files
* Open generated HTML files directly

## Technologies Used

* Python
* CustomTkinter
* python-docx
* Tkinter

## How to Run

Install required packages:

pip install customtkinter python-docx

Run the application:

python main.py
